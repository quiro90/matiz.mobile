# Esquema settings.json (móvil)
| Grupo | Claves |
|---|---|
| General | `schemaVersion`, `theme` (System/Light/Dark), `language` (System/Spanish/English) |
| Copiar | `defaultFormatId`, `hexUppercase`, `hexHash`, `copyOnPick` |
| Selector y generación | `wheelFocus`, `scaleAnchor` (Fixed500/Automatic), `scalePrefix`, `harmonyBalanceLightness`, `generationMode`, `harmonyKind`, `extractCount` |
| Burbuja y cámara | `bubbleEnabled`, `bubbleX/Y`, `cameraIntroShown` |
| Último color | `lastColor`, `lastHue`, `lastSaturation` |

`palettes.json` e `history.json` usan el mismo esquema que desktop. Ver [[Flujo de persistencia]].
