# Gestos
| Dónde | Gesto | Acción |
|---|---|---|
| Rueda | Tocar / arrastrar | Fijar / mover el color (confirma al soltar) |
| Rueda | Mantener 500 ms | Añadir punto a Personalizado |
| Punto en la rueda | Tocar / arrastrar / doble toque | Seleccionar y copiar / mover / quitar |
| Imagen | Un dedo | Lupa; al soltar, color actual |
| Imagen | Mantener quieto | Añadir el píxel a Personalizado |
| Imagen | Dos dedos / doble toque | Zoom y desplazar / ajustar ↔ 4× |
| Tarjeta | Tocar / mantener | Usar como principal / menú |
| Color de la paleta activa | Mantener y arrastrar / mantener sin mover | Reordenar / menú |
| Recientes | Tocar / mantener | Usar / copiar o añadir |
| Atrás | — | Cierra hoja → pantalla → Imagen→Rueda → pestaña→Crear → sale |
