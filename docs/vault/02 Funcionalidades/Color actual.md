# Color actual
- Fuente única de verdad: `ColorSession` de [[matiz_core]] (deshacer/rehacer de 50 pasos, anterior/actual). Deshacer y Rehacer están en la barra superior.
- Barra compacta: tocar **Anterior** lo restaura; tocar **Actual** abre la **hoja de detalle**: campo que acepta cualquier formato (con Pegar), R/G/B, H/S/B con −/+, Enfoque, Gris equivalente, Copiar todo, Exportar superpuestos (Anterior/Actual), todos los formatos con copiar y Recientes (con vaciar).
- El último color se restaura al abrir la app ([[Flujo de persistencia]]).
