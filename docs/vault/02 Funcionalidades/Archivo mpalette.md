# Archivo .mpalette
JSON idéntico al de desktop (`schemaVersion`, nombre, descripción, fechas y colores con `hex`, más `alpha` si ≠ 255). Lee fechas con los 7 decimales de .NET.
- Exportar: **Guardar en…** (diálogo del sistema) o **Compartir**.
- Importar: selector de archivos, [[Compartir hacia Matiz]] o Abrir con. Siempre crea una paleta nueva (sufijo " 2" si el nombre existe); una versión futura o un JSON inválido muestran un aviso sin cambiar nada.
