# Crear (pestaña)
- Barra de entradas: conmutador **Rueda | Imagen** (solo con imagen cargada), Abrir imagen (selector de fotos del sistema), Pegar (imagen o texto de color), [[Cámara]] y cerrar imagen.
- Zona principal: [[Rueda cromática]] + brillo, o la [[Imagen]] como foco.
- Debajo: barra de [[Color actual]] (Anterior | Actual, Copiar, Añadir a paleta), Recientes y una tira con la vista previa del modo de [[Generar]] (al tocarla lleva a esa pestaña).
- En pantallas ≥ 600 dp el panel va al costado.
