# ADR-M02 Pestañas inferiores
**Decisión** (del autor): Crear · Generar · Paletas en una barra inferior, en lugar de una sola pantalla con hojas.

**Consecuencia**: cada vista tiene más espacio. Para no perder la geometría de las armonías, [[Generar]] incluye una rueda compacta y [[Crear]] una vista previa del modo.
