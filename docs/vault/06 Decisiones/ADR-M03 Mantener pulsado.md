# ADR-M03 Mantener pulsado
**Decisión**: mantener pulsado (500 ms, con menos de 8 dp de movimiento) reemplaza al clic derecho para añadir secundarios.
- Apoyar el dedo no cambia el color hasta soltar o arrastrar, para no mover el principal al mantener.
- El doble toque solo se evalúa sobre puntos, para no retrasar el toque normal.
