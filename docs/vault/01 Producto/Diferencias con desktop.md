# Diferencias con desktop
| Desktop | Android |
|---|---|
| Captura global Alt+C con overlay y lupa | [[Compartir hacia Matiz]], pegar, [[Cámara]] y [[Burbuja flotante]] (una captura consentida) |
| Clic derecho = secundario | Mantener pulsado ([[ADR-M03 Mantener pulsado]]) |
| Doble clic en un punto = quitar | Doble toque |
| Rueda del ratón = zoom en imagen | Pinza con dos dedos; un dedo = lupa |
| Hover para "−" / tachito | Siempre visibles o menú al mantener |
| Una ventana con paneles | 3 pestañas: [[Crear]] · [[Generar]] · [[Paletas]] ([[ADR-M02 Pestañas inferiores]]) |
| Atajos, siempre visible, botones de ventana | No aplican |
| Idioma por defecto inglés | Idioma del sistema por defecto |

Lo que **no** cambia: el motor de color ([[Paridad con desktop]]), los formatos de copia y de código, el [[Archivo mpalette]] y el límite de 64 colores.
