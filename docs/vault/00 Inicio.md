# Matiz Android — Inicio

> App móvil (Flutter) para **tomar un color → entenderlo → armar una paleta → copiar / guardar → exportar**, pensada para pantallas táctiles. Proyecto hermano de Matiz desktop (`../matiz`, que no se modifica).
